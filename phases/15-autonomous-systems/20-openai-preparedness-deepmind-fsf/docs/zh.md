# OpenAI准备框架和DeepMind前沿安全框架

> OpenAI准备框架v2（2025年4月）引入研究类别——长程自主性、消极怠工、自主复制和适应、破坏安全机制——与跟踪类别不同。跟踪类别触发能力报告加由安全咨询组审查的安全机制报告。DeepMind的FSF v3（2025年9月，2026年4月17日添加跟踪能力水平）将自主性折叠到ML R&D和网络领域（ML R&D自主性水平1 = 以有竞争力的成本完全自动化AI R&D流程，与使用人类+AI工具相比）。FSF v3通过自动监控工具性推理误用明确解决欺骗性对齐。诚实的注释：PF v2中的研究类别（包括长程自主性）不自动触发缓解措施；政策语言是"潜在的"。DeepMind自己说如果工具性推理增强，自动监控"将不会长期保持足够"。

**类型:** 学习
**语言:** Python (stdlib, 三框架决策表差异工具)
**前置要求:** 第15阶段 · 19 (Anthropic RSP)
**时间:** ~45分钟

## 问题背景

第19课仔细阅读了Anthropic的扩展政策。本课通过阅读OpenAI和DeepMind的完成图景。三份文档是处理相同问题的表亲工件——前沿实验室何时应暂停或门控模型——它们在重要地方收敛于少量类别并分歧。

收敛：三者都将长程自主性标记为值得跟踪的能力类别。三者都承认欺骗行为（对齐伪造、消极怠工）为特定风险类别。三者都有内部审查机构。分歧：OpenAI将类别分为"跟踪"（强制缓解）和"研究"（无自动触发）。DeepMind将自主性折叠到两个领域而非单独命名。实验室命名跟踪vs研究，或关键vs中等，或Tier-1 vs Tier-2；能力所在桶的操作后果在不同实验室间不同。

一起阅读它们是有用的练习。相同能力在Anthropic可能是"强制缓解"，在OpenAI可能是"监控但不触发"，在DeepMind可能是"在特定领域跟踪"。政策姿态重要。

## 概念讲解

### OpenAI准备框架v2（2025年4月）

结构：

- **跟踪类别**：触发能力报告（模型能做什么）加安全机制报告（有哪些缓解措施）。部署前由安全咨询组审查。
- **研究类别**：实验室正在跟踪但尚未承诺特定缓解措施的模型能力。包括长程自主性、消极怠工、自主复制和适应、破坏安全机制。

v2中的关键框架：研究类别不自动触发缓解措施。政策语言是"潜在"缓解。这是要观察的具体增量：类别在跟踪vs研究中的位置是"门控"与"观察"之间的枢纽。

### DeepMind前沿安全框架v3（2025年9月；2026年4月17日添加跟踪能力水平）

结构：

- **关键能力水平（CCL）**：跨五个领域的能力阈值：网络、生物、ML R&D、CBRN、自主性（折叠到ML R&D和网络）。
- **跟踪能力水平**：2026年4月添加的额外粒度。具体示例：ML R&D自主性水平1 = 以有竞争力的成本完全自动化AI R&D流程，与使用人类+AI工具相比。
- **欺骗性对齐监控**：自动监控工具性推理误用的明确承诺。

自主性框架与OpenAI不同。DeepMind不将"自主性"保持为顶级领域；它折叠到自主性会造成危害的领域（ML R&D和网络）。论据是没有领域的自主性是能力而无风险；反论据是跨领域的自主性是框架应命名的元风险。

### 三者收敛之处

- 内部安全咨询组（命名Anthropic SAG、OpenAI SAG、DeepMind内部委员会）。高能力模型部署前审查。
- 明确提及欺骗性对齐/对齐伪造作为风险类别。
- 声明节奏上的常驻工件（Anthropic：前沿安全路线图、风险报告；OpenAI：能力和安全机制报告；DeepMind：FSF更新周期）。
- 承认仅监控防御有天花板。DeepMind明确："自动监控将不会长期保持足够。"

### 它们分歧之处

- **Anthropic**：v3.0中移除暂停承诺；AI R&D-4阈值是命名的下一门。
- **OpenAI**：跟踪vs研究分割；研究类别（包括长程自主性）不自动门控。
- **DeepMind**：自主性折叠到其他领域；2026年4月跟踪能力水平添加粒度。

### 消极怠工：使三者复杂化的特定能力

消极怠工（模型在评估上策略性表现不佳）在OpenAI的研究类别中。Anthropic的RSP v3.0通过评估上下文差距解决它（第1课）。DeepMind通过FSF v3中的欺骗性对齐监控解决它。

如果模型在评估上消极怠工，每个框架的能力阈值都被低估。框架仅当测量有效时才有效。这是为什么外部测量（第21课，METR）和对抗性评估除实验室自我评估外也是必需的。

### 政策阅读技能

- 定位：你关心的每个能力应在政策中可找到。如果不可找到，政策未覆盖它。
- 分类：它是跟踪（触发缓解）还是研究（跟踪但不触发）？OpenAI命名它；Anthropic和DeepMind有自己的等效物。
- 节奏：政策在声明时间表上更新，还是仅在特定事件后？声明节奏更强。
- 独立性：外部审查是强制还是可选？Anthropic与Apollo和美国AI安全研究所合作；OpenAI与METR；DeepMind主要与内部SAG。

## 动手实践

`code/main.py` 实现小型决策表差异工具。给定能力（自主性、欺骗性对齐、R&D自动化、网络升级等），它输出三政策各自如何分类能力，以及触发什么缓解措施。它是阅读辅助，非政策工具。

## 产出成果

`outputs/skill-cross-policy-diff.md` 使用三框架作为参考，产生特定能力的跨政策比较。

## 练习题

1. 运行 `code/main.py`。确认差异工具的输出与源文档可验证的至少两种能力匹配。

2. 完整阅读OpenAI准备框架v2。识别每个研究类别。对每个，写一句关于为什么它在研究而非跟踪中。

3. 完整阅读DeepMind FSF v3，加2026年4月跟踪能力水平更新。识别ML R&D自主性水平1的具体评估标准。你会如何外部测量它？

4. 消极怠工在OpenAI的研究类别中。设计会强制消极怠工模型揭示其实际能力的评估。参考第1课评估环境博弈讨论。

5. 比较三政策在特定能力（你的选择）上。命名你发现最严谨的政策分类和最不严谨的。用源文本证明。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|---|---|---|
| 准备框架 | "OpenAI的扩展政策" | PF v2（2025年4月）；跟踪vs研究类别 |
| 跟踪类别 | "强制缓解" | 触发能力+安全机制报告；SAG审查 |
| 研究类别 | "仅监控" | 跟踪但无自动缓解；包括长程自主性 |
| 前沿安全框架 | "DeepMind的扩展政策" | FSF v3（2025年9月）+ 跟踪能力水平（2026年4月） |
| CCL | "关键能力水平" | DeepMind每领域阈值（网络、生物、ML R&D、CBRN） |
| ML R&D自主性水平1 | "R&D自动化" | 以有竞争力的成本完全自动化AI R&D流程 |
| 消极怠工 | "策略性表现不佳" | 模型在评估上表现不佳；在OpenAI研究类别中 |
| 工具性推理 | "手段-目的推理" | 关于如何实现目标的推理；DeepMind监控目标 |
