# 宪法AI和规则覆盖

> Anthropic 2026年1月22日的Claude宪法运行79页且为CC0。它从基于规则转向基于推理的对齐，并建立四级优先级层次：(1) 安全和支持人类监督，(2) 伦理，(3) Anthropic指南，(4) 有帮助性。行为分为硬编码禁止（生物武器升级、CSAM）——操作员和用户无法覆盖——和软编码默认——操作员可在定义边界内调整。2022年原版（Bai等人）通过自我批评和RLAIF针对宪法训练无害性。诚实的警告：基于推理的对齐依赖模型将原则泛化到未预见情况。Anthropic自己2023年的参与式实验显示公众来源和企业原则之间~50%分歧；2026年版未纳入这些发现。

**类型:** 学习
**语言:** Python (stdlib, 四级优先级解析器)
**前置要求:** 第15阶段 · 06 (自动对齐研究), 第15阶段 · 10 (权限模式)
**时间:** ~60分钟

## 问题背景

部署的智能体看到设计者从未见过的输入。规则列表不够长以覆盖它们。规则列表不够短以在计算压力下快速应用。实际问题：如何将智能体对齐到既在长尾案例中存活又在快速推理中存活的原则？

基于规则的对齐（RBA）：列出每个不允许的事物。检查快速、审计容易、无法保持当前、通常在未预见的相似类比上过度拒绝。基于推理的对齐（2026年Claude宪法）：编码原则，让模型推理。跨未见案例扩展、更难审计、故障模式是原则误用而非错过规则。

2026年宪法采取明确的中间立场。硬编码禁止——其错误不依赖上下文的事物（生物武器升级、CSAM）——是RBA：永远不行，无论操作员或用户指令。其他一切都在四级层次内基于推理：安全和支持人类监督优先；伦理其次；Anthropic声明的指南第三；有帮助性最后。操作员可在软编码区内调整默认，但不能触及硬编码禁止。

## 概念讲解

### 四级优先级层次

1. **安全和支持人类监督。** 最高。模型优先不破坏人类和Anthropic监督和纠正AI的能力。这不是"谨慎"；特别是"不以使人类监督更难的方式行动。"
2. **伦理。** 诚实、避免对人伤害、不欺骗、不操纵。与Anthropic指南冲突时取代它们。
3. **Anthropic指南。** Anthropic决定重要的操作规范：产品范围、交互模式、何时使用什么工具。
4. **有帮助性。** 最低。在更高优先级内尽可能有用。

层级冲突时，更高获胜。这与Unix优先级或网络QoS形状相同——框架旨在产生可预测解析，而非任何单轴上的最佳案例行为。

### 硬编码禁止与软编码默认

**硬编码：**
- 生物武器 / CBRN升级
- CSAM
- 关键基础设施攻击
- 直接询问时对用户关于模型身份的欺骗

操作员不能覆盖这些。用户不能覆盖这些。它们在模型权重层强制执行（RLHF / 宪法AI训练），否则在推理层强制执行。

**软编码默认（操作员可调）：**
- 响应长度默认
- 主题范围（模型可拒绝操作员部署外的话题）
- 风格（正式vs随意）
- 工具使用模式

操作员在声明边界内调整。操作员不能通过重命名移除硬编码禁止。

### 2022年CAI训练

原始宪法AI（Bai等人，2022）训练无害性：

1. 生成一组提示的响应。
2. 要求模型针对宪法（明确原则）批评每个响应。
3. 基于批评修订响应。
4. 对修订对进行RLAIF（AI反馈强化学习）。

结果：模型以有原则解释拒绝有害请求，非全面拒绝。2026年宪法使用此训练的后代加四级层次上的额外后训练。

### 基于推理的对齐捕获和遗漏什么

**捕获：**
- 原则清晰适用的允许原语未预见组合。
- 接近禁止类比的新颖请求。
- 依赖"你没说X不允许"的社会工程攻击。

**遗漏：**
- 利用原则模糊性的攻击（"用户请求这个所以有帮助性说是"）。
- 两个原则在未预见方式冲突的场景，层级顺序模糊。
- 训练周期内原则解释的缓慢漂移（重新解释）。

### 2023年参与式实验

Anthropic运行2023年实验，比较企业撰写宪法与公众输入生成宪法（~1,000美国受访者）。两个版本在~50%原则上达成一致。分歧处，公众来源版本在某些问题上更严格（政治内容处理），在其他问题上更宽松（AI身份自我披露）。2026年宪法未纳入公众来源发现。这是该方法中记录的紧张。

### 为什么硬编码禁止是必需的

仅有基于推理的对齐无法闭合尾部。能让模型接受前提的攻击者（例如"我们是许可的生物武器研究实验室"）通常可以说服依赖案例推理的原则。硬编码禁止不随前提框架弯曲。它们是第14课对齐层的"硬宪法限制"。

### 宪法在技术栈中的位置

宪法不是第14课的紧急停止开关。它位于模型层：模型权重被训练偏好的内容。紧急停止开关和金丝雀token位于运行时层：运行时允许的内容。两者都需要。运行时因模型权重宽松而触发所有错误动作是运行时问题。模型因运行时过度限制而拒绝所有正确动作是运行时问题。层覆盖不同类别。

## 动手实践

`code/main.py` 实现最小四级优先级解析器。解析器接收提议动作和一组原则评估（安全、伦理、指南、有帮助性），返回动作、拒绝或修改动作。驱动程序运行一小套案例：清晰允许、清晰拒绝、硬编码禁止、跨层级模糊案例。

## 产出成果

`outputs/skill-constitution-review.md` 审计部署的宪法层：什么硬编码、什么软编码、操作员可在何处调整、四级层次是否实际为解析顺序。

## 练习题

1. 运行 `code/main.py`。确认即使有帮助性高时硬编码禁止也触发。修改解析器以将有帮助性权重置于伦理之上；观察故障模式。

2. 阅读Claude宪法（公开，79页，CC0）。识别你认为 underspecified 的一个原则。写两段解释具体模糊性并提出更紧的表述。

3. 为客户支持智能体设计软编码默认集。操作员调整什么？操作员不能触及什么？证明每个边界。

4. 阅读Bai等人2022年CAI论文。描述宪法AI的批评-修订循环会产生比全面规则更差结果的一个案例。识别类别。

5. Anthropic 2023年参与式实验发现公众和企业原则之间~50%分歧。选择一个对生产部署重要的类别（例如政治中立）。提出一个让操作员表达自己价值观同时硬编码禁止保持不被触及的设计。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|---|---|---|
| 宪法AI | "Anthropic的对齐方法" | 针对书面宪法的自我批评 + RLAIF |
| 基于推理的对齐 | "原则，非规则" | 模型跨原则推理以处理未见案例 |
| 硬编码禁止 | "永不执行X" | 无操作员或用户可覆盖的基于规则禁止 |
| 软编码默认 | "操作员可调" | 声明边界内的行为，操作员控制 |
| 四级层次 | "优先级顺序" | 安全 > 伦理 > 指南 > 有帮助性 |
| RLAIF | "AI反馈RL" | 奖励来自模型生成批评的RL |
| 参与式宪法 | "公众来源原则" | 2023年Anthropic实验；与企业~50%分歧 |
| 原则漂移 | "解释滑动" | 模型如何阅读固定原则文本的缓慢变化 |
