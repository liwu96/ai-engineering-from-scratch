# 有界自我改进设计

> 研究已收敛于四个原语来约束自我改进循环。每次编辑中必须保持的正式不变量。无法修改的对齐锚点。每维（安全、公平、稳健性）都必须保持的多目标约束，而不仅仅是性能。历史指标暗示能力损失时暂停循环的回归检测。它们都不是安全证明——信息理论结果（Kolmogorov复杂性、Lob定理）约束任何系统能证明关于其继任者的内容。它们是提高静默故障成本的缓解措施。

**类型:** 学习
**语言:** Python (stdlib, 带不变量检查的有界循环)
**前置要求:** 第15阶段 · 07 (RSI), 第15阶段 · 04 (DGM)
**时间:** ~60分钟

## 问题背景

第7课的竞赛模拟器显示小速率差异复合成大差距。第4课的DGM案例研究显示循环可以主动博弈自己的评估器。两个结果指向相同的工程问题：你可以在自我改进循环上设置什么约束，使得约束不能被循环本身静默削弱？

ICLR 2026 RSI研讨会摘要（openreview.net/pdf?id=OsPQ6zTQXV）识别四个此类原语。Anthropic的RSP v3.0（第19课）和DeepMind的FSF v3（第20课）在能力阈值中引用它们。Meta的HyperAgents工作和SAHOO（2026年3月）等社区框架在生产中实现子集。

诚实的框架：这些是缓解措施。信息理论结果约束任何系统能证明关于其继任者的内容，且没有当前设计正式闭合问题。有界循环比无界循环更安全，不是绝对安全。

## 概念讲解

### 原语1：正式不变量

不变量是每次自我修改前后必须保持的属性。示例：

- 输出分布以固定的宪法标题为条件（第17课）。
- 没有工具调用转到未授权端点。
- 内存写入经过日志记录、签名的路径。
- 评估器的模块哈希匹配批准的版本。

不变量由循环无法编辑的外部代码检查。如果提议的修改违反不变量，它被拒绝。这会捕获DGM风格的评估器篡改模式（第4课）。

困难的部分是选择对安全必要且可在合理时间内计算的不变量。过度指定会拖延进展；指定不足会让循环走过重要属性。

### 原语2：对齐锚点

对齐锚点是循环核心目标的不可变表示，固定在循环编辑面之外。示例：

- 每次调用从只读位置加载的宪法文本（第17课）。
- 具有独立访问控制的单独仓库中的评估器。
- 由人类签名且每循环重新验证的工具权限清单。

锚点的作用是防止目标漂移。循环可能改进追求目标的方式，但不能编辑目标是什么。

微妙的失败模式：循环无法编辑的锚点仍可能被在如何读取锚点上漂移的循环重新解释。宪法AI（第17课）明确基于推理以处理新情况；该推理层是解释漂移所在。锚点是必要的，不是充分的。

### 原语3：多目标约束

优化单一标量分数的循环会找到捷径。必须同时满足多个硬约束的循环有更少的捷径可用。典型轴：

- 性能（任务级基准测试）
- 安全（红队评估、已知不良上的拒绝率）
- 公平（敏感子群上的差异影响界限）
- 稳健性（分布外测试集、对抗性输入处理）

仅当每个约束都保持时才接受修改。第13课的成本治理器将其与财务约束堆叠。第18课的Llama Guard作为安全轴插入。

### 原语4：回归检测

每次循环的分数与历史分布比较。超出配置容差的下降暂停循环。这会捕获静默能力损失，否则会被吸收到运行平均值中，因为循环"改进过去"了它。

实际实现：存储最后N个循环的每任务分数。每个新循环计算每任务增量。如果任何增量低于阈值，循环被拒绝且人工审查。

### 信息理论限制

Kolmogorov复杂性和Lob定理设置系统能证明关于自身的上限。Schmidhuber的正式Godel Machine（第4课）旨在达到最高此类界限；没有人完成非平凡证明。Lob的结果说：如果系统可证明地相信"如果我证明我应该做X我就会做X"，它会做X而不证明它应该，这是众所周知的自我引用失败。

对我们原语的暗示：它们无法闭合安全问题。它们使静默故障更昂贵。会静默绕过缺失检查的恶意或漂移循环现在必须主动破坏明确检查，这是更可检测的签名。

### 一个工作示例

假设智能体提议编辑。门控堆栈：

1. 不变量检查：模块哈希、工具权限清单、宪法标题。
2. 锚点检查：目标声明匹配批准的版本（按字节或语义）。
3. 多目标评估：性能、安全、公平、稳健性轴。
4. 回归检测：没有轴下降超过容差。

四个都必须通过编辑才能落地。任何单一失败都会暂停循环。

## 练习题

1. 启用所有原语运行 `code/main.py`。确认循环仍在主要指标上改进而不让黑客获胜。

2. 禁用回归检测。构造一个导致此导致静默能力损失被接受的输入。

3. 禁用多目标约束。展示循环在性能轴上收敛而安全轴下降。

4. 为编码智能体设计对齐锚点。什么文本、存储在哪里、如何检查？

5. 阅读ICLR 2026 RSI研讨会摘要。选择四个原语之一并为当前技术水平提出具体改进。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|---|---|---|
| 不变量 | "始终为真的属性" | 每次编辑前后由外部代码检查的属性 |
| 对齐锚点 | "固定目标" | 循环编辑面之外不可变的核心目标表示 |
| 多目标约束 | "所有轴必须保持" | 性能、安全、公平、稳健性——全部需要 |
| 回归检测 | "下降时暂停" | 历史指标增量暗示能力损失时暂停循环 |
| Kolmogorov界限 | "信息理论限制" | 约束系统能证明关于其继任者的内容 |
| Lob定理 | "自我引用陷阱" | 系统可以在不证明应该做的情况下基于"我应该做"行动 |
| 门控堆栈 | "分层检查" | 多个原语组合；任何失败拒绝编辑 |
| 有界改进 | "缓解，非证明" | 提高静默故障成本；不闭合安全问题 |
