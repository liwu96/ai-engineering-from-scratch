# MDP、状态、动作与奖励

> 马尔可夫决策过程是五个东西:状态、动作、转移、奖励、折扣。强化学习中的一切——Q-learning、PPO、DPO、GRPO——都在这个结构上优化。学一次,免费读懂强化学习其余部分。

## 问题背景

你写象棋机器人。或库存规划器。或交易智能体。或训练推理模型的PPO循环。四个不同领域,一个惊人事实:全部坍缩到同一数学对象。

监督学习给`(x, y)`配要求拟合函数。强化学习不给标签——只有状态流、采取的动作和标量奖励。移动赢游戏了吗?补货决策省钱了吗?交易盈利了吗?大语言模型刚产生的词元导致评判给更高奖励了吗?

形式化后才能从这流学习。"我看到的"、"我做的"、"接下来发生什么"、"那有多好"——每个须成为可推理对象。形式化是马尔可夫决策过程。阶段9每个强化学习算法,包括末尾RLHF和GRPO循环,都在这结构上优化。

## 概念讲解

![马尔可夫决策过程:状态、动作、转移、奖励、折扣](../assets/mdp.svg)

**五个对象。**

- **状态**`S`。智能体决策所需的一切。GridWorld中是格子。象棋中是棋盘。大语言模型中是上下文窗口加任何记忆。
- **动作**`A`。选择。上/下/左/右移动。走一步。发出词元。
- **转移**`P(s' | s, a)`。给定状态`s`和动作`a`,下一状态分布。象棋确定,库存随机,大语言模型解码几乎确定。
- **奖励**`R(s, a, s')`。标量信号。胜=+1,败=-1。收入减成本。GRPO中对数似然比项。
- **折扣**`γ ∈ [0, 1)`。未来奖励相比现在算多少。`γ = 0.99`买~100步视界;`γ = 0.9`买~10步。

**马尔可夫性质**`P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`。未来仅依赖当前状态。不依赖,状态表示不完整——不是方法失败,是状态失败。

**策略与回报。**策略`π(a | s)`映射状态到动作分布。回报`G_t = r_t + γ r_{t+1} + γ² r_{t+2} + …`是未来奖励折现和。价值`V^π(s) = E[G_t | s_t = s]`是从`s`开始在策略`π`下期望回报。Q值`Q^π(s, a) = E[G_t | s_t = s, a_t = a]`是从特定动作开始的期望回报。每个强化学习算法估计这两个之一,然后改进`π`。

**贝尔曼方程。**本阶段所用一切固定点方程:

`V^π(s) = Σ_a π(a|s) Σ_{s', r} P(s', r | s, a) [r + γ V^π(s')]`
`Q^π(s, a) = Σ_{s', r} P(s', r | s, a) [r + γ Σ_{a'} π(a'|s') Q^π(s', a')]`

这些把期望回报拆成"这步奖励"加"落点的折现价值"。递归。阶段9每个算法要么迭代这方程到收敛(动态规划),要么从中采样(蒙特卡洛),要么一步自举(时序差分)。

## 动手实践

### Step 1:微小确定MDP

4×4 GridWorld。智能体左上开始,右下终止,每步奖励-1,动作`{上, 下, 左, 右}`。见`code/main.py`。

```python
GRID = 4
TERMINAL = (3, 3)
ACTIONS = {"上": (-1, 0), "下": (1, 0), "左": (0, -1), "右": (0, 1)}

def step(state, action):
    if state == TERMINAL:
        return state, 0.0, True
    dr, dc = ACTIONS[action]
    r, c = state
    nr = min(max(r + dr, 0), GRID - 1)
    nc = min(max(c + dc, 0), GRID - 1)
    return (nr, nc), -1.0, (nr, nc) == TERMINAL
```

五行。整个环境。确定转移,恒定步惩罚,吸收终止状态。

### Step 2:展开策略

策略是状态到动作分布的函数。最简单:均匀随机。

```python
def uniform_policy(state):
    return {a: 0.25 for a in ACTIONS}

def rollout(policy, max_steps=200):
    s, total, steps = (0, 0), 0.0, 0
    for _ in range(max_steps):
        a = sample(policy(s))
        s, r, done = step(s, a)
        total += r
        steps += 1
        if done:
            break
    return total, steps
```

随机策略跑1000次。这4×4板平均回报约-60到-80。最优回报-6(右下直路径)。缩小差距是阶段9全部。

### Step 3:贝尔曼方程精确计算`V^π`

小MDP贝尔曼方程是线性系统。枚举状态,应用期望,迭代到值不变。

```python
def policy_evaluation(policy, gamma=0.99, tol=1e-6):
    V = {s: 0.0 for s in all_states()}
    while True:
        delta = 0.0
        for s in all_states():
            if s == TERMINAL:
                continue
            v = 0.0
            for a, pi_a in policy(s).items():
                s_next, r, _ = step(s, a)
                v += pi_a * (r + gamma * V[s_next])
            delta = max(delta, abs(v - V[s]))
            V[s] = v
        if delta < tol:
            return V
```

这是迭代策略评估。Sutton & Barto第一个算法,其后每个强化学习方法理论基础。

### Step 4:`γ`是带物理意义的超参数

有效视界约`1 / (1 - γ)`。`γ = 0.9`→10步。`γ = 0.99`→100步。`γ = 0.999`→1000步。

太低智能体短视。太高信用分配变噪,因许多早步分享远未来奖励责任。大语言模型RLHF典型用`γ = 1`因情节短且有界。控制任务用`0.95–0.99`。长视界策略游戏用`0.999`。

## 陷阱

- **非马尔可夫状态。**需最后三观察决策,"状态"不只当前观察。修复:堆帧(Atari上DQN堆4)或用循环状态(观察上LSTM/GRU)。
- **稀疏奖励。**仅胜奖励使大状态空间学习几乎不可能。塑形奖励(中间信号)或用模仿启动(阶段9课程09)。
- **奖励博弈。**优化代理奖励常产生病态行为。OpenAI赛船智能体原地转圈永远捡道具而非完成比赛。始终从目标结果定义奖励,非代理。
- **折扣错误指定。**无限视界任务上`γ = 1`使每个值无限。始终用有限视界或`γ < 1`限制。
- **奖励尺度。**奖励{+100, -100}vs {+1, -1}给出相同最优策略但梯度幅度差巨大。PPO/DQN前归一化到`[-1, 1]`附近。

## 实际应用

2026栈在写代码前把每个强化学习管道归约为MDP:

| 情境 | 状态 | 动作 | 奖励 | γ |
|------|------|------|------|---|
| 控制(运动、操纵) | 关节角度+速度 | 连续力矩 | 任务特定塑形 | 0.99 |
| 游戏(象棋、围棋、扑克) | 棋盘+历史 | 合法移动 | 胜=+1/败=-1 | 1.0(有限) |
| 库存/定价 | 库存+需求 | 订单量 | 收入-成本 | 0.95 |
| 大语言模型RLHF | 上下文词元 | 下个词元 | 末尾奖励模型分数 | 1.0(情节~200词元) |
| 推理GRPO | 提示词+部分响应 | 下个词元 | 末尾验证器0/1 | 1.0 |

写训练循环前先写五元组。大多数"强化学习不工作"bug报告追溯到纸面上MDP形式化已破损。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|------------|----------|
| MDP | "强化学习设置" | 元组`(S, A, P, R, γ)`满足马尔可夫性质。 |
| 状态 | "智能体看到的" | 所选策略类下未来动态充分统计量。 |
| 策略 | "智能体行为" | 条件分布`π(a | s)`或确定映射`s → a`。 |
| 回报 | "总奖励" | 从当前步开始折现和`Σ γ^t r_t`。 |
| 价值 | "状态多好" | 从`s`开始在`π`下期望回报。 |
| Q值 | "动作多好" | 从`s`开始以动作`a`在`π`下期望回报。 |
| 贝尔曼方程 | "动态规划递归" | 价值/Q一步奖励加折现后继值固定点分解。 |
| 折扣`γ` | "未来vs现在" | 远未来奖励几何权重;有效视界`~1/(1-γ)`。 |
