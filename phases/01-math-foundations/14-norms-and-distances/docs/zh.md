# 范数与距离

> 你的距离函数定义"相似"的含义。选错会让下游一切崩溃。

**类型:** 构建
**语言:** Python
**前置要求:** 第1阶段, 课程01 (线性代数直觉), 02 (向量、矩阵与运算)
**时间:** ~90分钟

## 学习目标

- 从零实现L1、L2、余弦、马氏距离、Jaccard和编辑距离函数
- 为给定ML任务选择合适距离度量并解释替代方案为何失败
- 将L1和L2范数联系到LASSO和Ridge正则化及其几何约束区域
- 展示相同数据集在不同度量下产生不同最近邻

## 问题背景

你有两个向量。可能是词嵌入。可能是用户画像。可能是像素数组。你需要知道: 它们多近?

答案完全取决于你选哪个距离函数。两个数据点可以在一个度量下是最近邻，在另一个下很远。你的KNN分类器、推荐引擎、向量数据库、聚类算法、损失函数——都依赖这个选择。选错模型优化错误的东西。

没有通用最佳距离。L2适合空间数据。余弦相似度主导NLP。Jaccard处理集合。编辑距离处理字符串。马氏距离考虑相关性。Wasserstein移动概率质量。每个编码不同"相似"假设。

本课程从零构建每个主要距离函数，展示何时每个是正确工具，演示相同数据如何根据度量产生完全不同最近邻。

## 概念讲解

### 范数: 衡量向量大小

范数衡量向量"大小"。两向量间距离可写成差的范数: d(a, b) = ||a - b||。所以理解范数就是理解距离。

### L1范数(曼哈顿距离)

L1范数求所有分量绝对值之和。

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

叫曼哈顿距离因为它测量你沿只能沿轴移动的城市网格走多远。没有对角线。

```
点A = (1, 1)
点B = (4, 5)

L1距离 = |4-1| + |5-1| = 3 + 4 = 7

网格上，你走3块东4块北。
```

何时用L1:
- 高维稀疏数据(文本特征、one-hot编码)
- 想对异常值鲁棒(单个大差异不主导)
- 特征选择问题(L1正则化促进稀疏)

与L1正则化(Lasso)联系: 损失函数加 ||w||_1 惩罚权重绝对值之和。这推动小权重到精确零，自动特征选择。L1惩罚在权重空间创建菱形约束区域，菱形角在轴上某些权重为零。

与损失函数联系: 平均绝对误差(MAE)是预测与目标平均L1距离。线性惩罚所有误差，比MSE对异常值鲁棒。

### L2范数(欧几里得距离)

L2范数是直线距离。分量平方和平方根。

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

这是几何课学的距离。n维毕达哥拉斯。

```
点A = (1, 1)
点B = (4, 5)

L2距离 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

直线，斜穿网格。
```

何时用L2:
- 低中维连续数据
- 特征尺度可比
- 物理距离(空间数据、传感器读数)
- 像素级图像相似

与L2正则化(Ridge)联系: 损失函数加 ||w||_2^2 惩罚大权重。不同于L1，不推权重到零。比例收缩所有权重向零。L2惩罚创建圆形约束区域，轴上无角。权重变小但很少精确零。

与损失函数联系: 平均平方误差(MSE)是L2距离平方平均。平方更重惩罚大误差。

```
MAE (L1损失):  |y - y_hat|         线性惩罚。对异常值鲁棒。
MSE (L2损失):  (y - y_hat)^2       二次惩罚。对异常值敏感。
```

### Lp范数: 通家族

L1和L2是Lp范数特例:

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

不同p值产生不同形状"单位球"(距离1所有点):

```
p=1:    菱形      (角在轴上)
p=2:    圆/球      (常见圆球)
p=3:    超椭圆       (圆角方)
p=inf:  方/超立方   (沿轴平边)
```

### L-无穷范数(Chebyshev距离)

p趋无穷，Lp范数收敛到最大绝对分量。

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

两点间距离由它们差异最大的单维决定。其他所有维忽略。

```
点A = (1, 1)
点B = (4, 5)

L-inf距离 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

何时用L-infinity:
- 任一单维最坏偏离重要
- 棋盘(象棋王走L-infinity: 任一方向一步代价1)
- 制造容忍度(每维必须在规格内)

### 余弦相似度与余弦距离

余弦相似度测量两向量角度，忽略大小。

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

范围-1(反方向)到+1(同方向)。垂直向量余弦相似度0。

余弦距离转为距离: cosine_distance = 1 - cosine_similarity。范围0(同向)到2(反向)。

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

为什么余弦主导NLP和嵌入: 文本中，文档长度不应影响相似度。一篇关于猫的文章两倍长另一篇关于猫的文章应该仍"相似"。余弦相似度忽略大小(长度)只关心方向。同词分布但不同长度的两文档同向，余弦相似度1.0。

何时用余弦相似度:
- 文本相似(TF-IDF向量、词嵌入、句子嵌入)
- 大小是噪声方向是信号的领域
- 推荐系统(用户偏好向量)
- 嵌入搜索(向量数据库几乎总用余弦或点积)

### 点积相似度vs余弦相似度

两向量点积:

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

余弦相似度是点积被两大小归一化。两向量都单位归一化(大小=1)时，点积和余弦相似度相同。

```
如果 ||a|| = 1 且 ||b|| = 1:
    a . b = cos(a和b间角度)
```

不同时: 点积包含大小信息。更大向量点积更高。这在一些检索系统中重要，想要"热门"项排名更高。大小充当隐式质量或重要性信号。

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

两者同意方向，但点积也反映大小。
```

实践中:
- 纯方向相似用余弦相似度
- 大小携带有意义信息用点积
- 很多向量数据库(Pinecone, Weaviate, Qdrant)让你选择
- 嵌入L2归一化时，选择不重要

### 马氏距离

欧几里得距离平等对待所有维。但如果特征相关或有不同尺度，L2给出误导结果。

马氏距离考虑数据协方差结构。

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

其中S是数据协方差矩阵。

直觉: 马氏距离先去相关和归一化数据(白化)，然后在那变换空间算L2距离。如果S是单位矩阵(不相关、单位方差特征)，马氏距离简化为欧几里得距离。

```
例子: 身高体重相关。
某人6'2"和180磅不异常。
某人5'0"和180磅异常。

欧几里得距离可能说他们距均值同样远。
马氏距离正确识别第二个是异常值
因为考虑身高体重相关性。
```

何时用马氏距离:
- 异常值检测(距均值马氏距离大的是异常值)
- 特征有不同尺度和相关性的分类
- 有足够数据估计可靠协方差矩阵
- 制造质量控制(多变量过程监控)

### Jaccard相似度(用于集合)

Jaccard相似度测量两集合重叠。

```
J(A, B) = |A交B| / |A并B|
```

范围0(无重叠)到1(相同集合)。Jaccard距离 = 1 - Jaccard相似度。

```
A = {猫, 狗, 鱼}
B = {猫, 鸟, 鱼, 蛇}

交集 = {猫, 鱼}         大小 = 2
并集 = {猫, 狗, 鱼, 鸟, 蛇}  大小 = 5

Jaccard相似度 = 2/5 = 0.4
Jaccard距离 = 0.6
```

何时用Jaccard:
- 比较标签、类别或特征集合
- 基于词存在(非频率)的文档相似
- 近重复检测(Jaccard的MinHash近似)
- 比较二值特征向量(存在/缺失数据)
- 评估分割模型(交集除并集 = Jaccard)

### 编辑距离(Levenshtein距离)

编辑距离计算变换一个字符串到另一个所需最少单字符操作。操作: 插入、删除、替换。

```
"kitten" -> "sitting"

kitten -> sitten  (替换 k -> s)
sitten -> sittin  (替换 e -> i)
sittin -> sitting (插入 g)

编辑距离 = 3
```

用动态规划计算。填充矩阵，条目是字符串A前i字符和字符串B前j字符间编辑距离。

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

何时用编辑距离:
- 拼写检查和纠正
- DNA序列比对(带加权操作)
- 模糊字符串匹配
- 混乱文本数据去重

### KL散度(非距离，但像距离用)

KL散度衡量一概率分布如何不同于另一。课程09覆盖，但属于此讨论因为人们当"距离"用尽管它不是。

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

关键性质: KL散度非对称。

```
D_KL(P || Q) != D_KL(Q || P)
```

这意味它不符合距离度量基本要求。也不满足三角不等式。它是散度，非距离。

前向KL (D_KL(P || Q))是"均值寻求": Q试图覆盖P所有模。
反向KL (D_KL(Q || P))是"模寻求": Q聚焦P单模。

何时看到KL散度:
- VAE (ELBO中KL项推动潜分布向先验)
- 知识蒸馏(学生试图匹配教师分布)
- RLHF (KL惩罚保持微调模型接近基础模型)
- 策略梯度方法(约束策略更新)

### Wasserstein距离(Earth Mover距离)

Wasserstein距离衡量变换一概率分布到另一所需最少"功"。想成: 如果一分布是堆土另一是坑，你要移动多少土多远?

```
W(P, Q) = 对所有传输计划gamma取下界 E[d(x, y)]
```

对1D分布，简化为累积分布函数绝对差积分:

```
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

为什么Wasserstein重要:
- 是真正度量(对称，满足三角不等式)
- 分布不重叠时也提供梯度(KL散度趋向无穷)
- 这性质使其成为Wasserstein GAN (WGAN)核心，解决原始GAN训练不稳定

```
无重叠分布:

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL散度: 无穷 (零的对数)
Wasserstein: 4 (移动所有质量4格)

Wasserstein给有意义梯度。KL不给。
```

何时用Wasserstein:
- GAN训练 (WGAN, WGAN-GP)
- 比较可能不重叠分布
- 最优传输问题
- 图像检索(比较颜色直方图)

### 为什么不同任务需要不同距离

| 任务 | 最佳距离 | 原因 |
|------|---------|------|
| 文本相似 | 余弦 | 大小是噪声，方向是意义 |
| 图像像素比较 | L2 | 空间关系重要，特征尺度可比 |
| 稀疏高维特征 | L1 | 鲁棒，不放大罕见大差异 |
| 集合重叠(标签、类别) | Jaccard | 数据天然集合值，非向量 |
| 字串匹配 | 编辑距离 | 操作映射人类编辑直觉 |
| 异常值检测 | 马氏距离 | 考虑特征相关性和尺度 |
| 比较分布 | KL散度 | 衡量用Q而非P损失信息 |
| GAN训练 | Wasserstein | 分布不重叠也提供梯度 |
| 嵌入(向量DB) | 余弦或点积 | 嵌入训练编码意义在方向 |
| 推荐 | 点积 | 大小可编码流行度或置信度 |
| DNA序列 | 加权编辑距离 | 替换代价因核苷酸对变化 |
| 制造QC | L-infinity | 任一维最坏偏离重要 |

### 与损失函数联系

损失函数是应用于预测vs目标的距离函数。

```
损失函数       用距离       行为
MSE                 L2平方             重惩罚大误差
MAE                 L1                 等惩罚所有误差
Huber损失          大误差L1,   两者最佳: 对异常值鲁棒,
                    小误差L2    零附近平滑梯度
交叉熵       KL散度          衡量分布不匹配
Hinge损失          max(0, margin - d)     只惩罚低于margin
Triplet损失        L2 (典型)         拉近正例，推开
                                           负例
Contrastive损失    L2                 相似对近，不相似
                                           对超margin
```

### 与正则化联系

正则化给损失函数加权重范数惩罚。

```
L1正则化 (Lasso):   loss + lambda * ||w||_1
  -> 稀疏权重。某些权重精确为零。
  -> 自动特征选择。
  -> 解有角(零处不可微)。

L2正则化 (Ridge):   loss + lambda * ||w||_2^2
  -> 小权重。所有权重向零收缩。
  -> 无特征选择(无精确零)。
  -> 处处平滑解。

Elastic Net:                  loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> 结合L1稀疏和L2稳定。
  -> 相关特征组一起保留或丢弃。
```

为什么L1产生稀疏但L2不: 2D权重空间图约束区域。L1是菱形，L2是圆。损失函数轮廓(椭圆)最可能触菱形于角，那里一权重零。它们触圆于平滑点，两权重非零。

### 最近邻搜索

每个距离函数暗示最近邻搜索问题: 给查询点，找数据集中最近点。

精确最近邻搜索是O(n * d)每查询在n点d维数据集。大数据集太慢。

近似最近邻(ANN)算法牺牲少量精度换取巨大加速:

```
算法         方法                      使用
KD-trees          轴对齐空间分割   scikit-learn (低维)
Ball trees        嵌套超球            scikit-learn (中维)
LSH               随机哈希投影        近重复检测
HNSW              分层可导航         FAISS, Qdrant, Weaviate
                  小世界图
IVF               带簇搜索的        FAISS (十亿级)
                  倒排文件索引
Product quant.    压缩向量，搜索       FAISS (内存受限)
                  压缩空间
```

HNSW (分层可导航小世界)是现代向量数据库主导算法。它构建多层图，每节点连接其近似最近邻。搜索从顶层(稀疏，长跳)下降到底层(密集，短跳)。

## 实际应用

最常见实际应用: 向量数据库找相似项。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"最相似项0的前5: {top_k}")
print(f"相似度: {similarities[top_k]}")
```

当你调用 `model.encode(text)` 然后搜索向量数据库，这就是内部发生。嵌入模型映射文本到向量。向量数据库计算查询向量与每个存储向量余弦相似度(或点积)，用ANN算法避免检查全部。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|----------|
| 范数 | "向量大小" | 映射向量到非负标量满足三角不等式、绝对齐次性、零向量才零的函数 |
| L1范数 | "曼哈顿距离" | 绝对分量值之和。优化中产生稀疏。对异常值鲁棒 |
| L2范数 | "欧几里得距离" | 分量平方和平方根。欧几里得空间直线距离 |
| Lp范数 | "广义范数" | 绝对分量p次幂和的p次根。L1和L2是特例 |
| L-无穷范数 | "最大范数" 或 "Chebyshev距离" | 最大绝对分量值。Lp在p趋无穷极限 |
| 余弦相似度 | "向量间角度" | 点积被两大小归一化。范围-1到+1。忽略向量长度 |
| 余弦距离 | "1减余弦相似度" | 余弦相似度转距离。范围0到2 |
| 点积 | "未归一化余弦" | 分量逐乘之和。等于余弦相似度乘两大小 |
| 马氏距离 | "感知相关距离" | 用数据协方差矩阵白化(去相关归一化)空间中L2距离 |
| Jaccard相似度 | "集合重叠" | 交集大小除并集大小。用于集合，非向量 |
| 编辑距离 | "Levenshtein距离" | 变换一个字符串到另一个最少插入、删除和替换 |
| KL散度 | "分布间距离" | 非真正距离(不对称)。衡量用Q编码P额外比特 |
| Wasserstein距离 | "推土机距离" | 从一分布传输质量到另一最少功。真正度量 |
| 近似最近邻 | "ANN搜索" | 算法(HNSW, LSH, IVF)比精确搜索快很多找近似最近点 |
| HNSW | "向量DB算法" | 分层可导航小世界图。快速近似最近邻搜索多层图 |
| L1正则化 | "Lasso" | 损失加权重L1范数。驱动权重到零(稀疏) |
| L2正则化 | "Ridge" 或 "权重衰减" | 损失加权重平方L2范数。向零收缩权重无稀疏 |
| Elastic Net | "L1 + L2" | 结合L1和L2正则化。比单独更好处理相关特征组 |
