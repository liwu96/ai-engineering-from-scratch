# 机器学习统计学

> 统计学告诉你模型是否真正有效还是只是运气好。

**类型:** 构建
**语言:** Python
**前置要求:** 第1阶段, 课程06 (概率与分布), 07 (贝叶斯定理)
**时间:** ~120分钟

## 学习目标

- 从零计算描述性统计、Pearson/Spearman相关和协方差矩阵
- 执行假设检验(t检验、卡方)并正确解释p值和置信区间
- 用bootstrap重采样为任意度量构建置信区间无需分布假设
- 用效应量区分统计显著性与实践显著性

## 问题背景

你训练两个模型。模型A测试集得分0.87。模型B得分0.89。你部署模型B。三周后生产指标比之前差。发生了什么?

模型B并未真正胜过模型A。0.02差异是噪声。测试集太小，或方差太高，或两者。你发布了伪装成改进的随机性。

这经常发生。Kaggle排行榜震荡。论文不可复现。基于几百样本宣布胜者的A/B测试。根本原因相同: 有人跳过统计。

统计学给你区分信号噪声的工具。它告诉你差异何时真实，应多自信，需要多少数据才能信任结果。每个ML流水线、每个模型比较、每个实验需要统计。没有它，你在猜测。

## 概念讲解

### 描述性统计: 总结数据

建模前，需要知道数据什么样。描述性统计将数据集压缩成几个数字捕捉形状。

**中心趋势度量**回答"中间在哪?"

```
均值:   所有值之和 / 计数
        mu = (1/n) * sum(x_i)

中位数: 排序后中间值
        对异常值鲁棒。如有[1, 2, 3, 4, 1000]，均值202
        但中位数3。

众数:   最频繁值
        对类别数据有用。连续数据很少有用。
```

均值是平衡点。中位数是中途标记。它们分离时分布偏斜。收入分布均值>>中位数(亿万富翁右偏)。训练时损失分布常均值<<中位数(易样本左偏)。

**离散度量**回答"数据多分散?"

```
方差:   均值平方偏差平均
            sigma^2 = (1/n) * sum((x_i - mu)^2)

标准差:  方差平方根
                     sigma = sqrt(sigma^2)
                     与数据同单位，更可解释。

范围:      最大 - 最小
            对异常值敏感。几乎从不单独有用。

IQR:        Q3 - Q1 (四分位距)
            中间50%数据范围。
            对异常值鲁棒。用于箱线图和异常值检测。
```

**百分位数**将排序数据分成100等分。第25百分位(Q1)意味25%值在此下。第50百分位是中位数。第75百分位是Q3。

```
延迟监控:
  P50 = 中位延迟        (典型用户体验)
  P95 = 95百分位       (坏但非最坏)
  P99 = 99百分位       (尾部延迟，常10倍中位数)
```

ML中你关心推理延迟、预测置信分布和误差分布百分位。低平均误差但糟糕P99误差的模型对安全关键应用可能无用。

**样本vs总体统计。** 从样本计算方差时，除(n-1)而非n。这是Bessel修正。补偿事实样本均值非真实总体均值。n在分母，系统低估真实方差。(n-1)，估计无偏。

```
总体方差: sigma^2 = (1/N) * sum((x_i - mu)^2)
样本方差:     s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

实践: n大(数千样本)时差异可忽略。n小(几十样本)时重要。

### 相关: 变量如何一起变化

相关测量两变量线性关系强度和方向。

**Pearson相关系数**测量线性关联:

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1:  完美正线性关系
r = -1:  完美负线性关系
r =  0:  无线性关系 (但可能有非线性!)

范围: [-1, 1]
```

Pearson假设关系线性且两变量大致正态分布。对异常值敏感。单极端点可从0.1拖到0.9。

**Spearman秩相关**测量单调关联:

```
1. 用秩(1, 2, 3, ...)替换每个值
2. 计算秩上Pearson相关

Spearman捕捉任意单调关系，非仅线性。
如果 y = x^3，Pearson给 r < 1 但 Spearman给 rho = 1。
```

**何时用哪个:**

```
Pearson:    两变量连续且大致正态。
            你关心线性关系具体。
            无极端异常值。

Spearman:   序数数据(排名、评分)。
            数据非正态分布。
            你怀疑单调但非线性关系。
            有异常值。
```

**金科玉律:** 相关不意味因果。冰淇淋销量和溺水死亡相关因为夏天两者增加。模型精度和参数数相关，但加参数不自动提高精度(见: 过拟合)。

### 协方差矩阵

两变量间协方差测量它们如何一起变化:

```
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0:  X和Y趋向一起增加
Cov(X, Y) < 0:  X增加时，Y趋向减少
Cov(X, Y) = 0:  无线性共动
```

对d特征，协方差矩阵C是d x d矩阵，C[i][j] = Cov(feature_i, feature_j)。对角条目C[i][i]是各特征方差。

```
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

性质:
  - 对称: C[i][j] = C[j][i]
  - 半正定: 所有特征值 >= 0
  - 对角 = 方差
  - 非对角 = 协方差
```

**与PCA联系。** PCA对协方差矩阵特征分解。特征向量是主成分(最大方差方向)。特征值告诉你每个成分捕获多少方差。这正是课程10覆盖内容，但现在你明白为什么协方差矩阵是正确分解对象: 它编码数据所有对线性关系。

**与相关联系。** 相关矩阵是标准化变量协方差矩阵(每个除标准差)。相关归一化协方差使所有值在[-1, 1]。

### 假设检验

假设检验是在不确定性下决策框架。你从声称开始，收集数据，确定数据是否与声称一致。

**设置:**

```
零假设(H0):        默认假设，通常"无效果"
备择假设(H1): 你试图展示的

例子:
  H0: 模型A和模型B精度相同
  H1: 模型B精度高于模型A
```

**p值**是假设H0为真时看到与你观测同样极端数据的概率。它非H0为真的概率。这是统计中最常见误解。

```
p值 = P(此极端数据 | H0为真)

如果p值 < alpha (典型0.05):
    拒绝H0。结果"统计显著。"
如果p值 >= alpha:
    未能拒绝H0。你没有足够证据。
    这不意味H0为真。
```

**置信区间**给参数合理值范围:

```
均值95%置信区间:
    x_bar +/- z * (s / sqrt(n))

z = 1.96 对95%置信

解释: 如果你重复此实验多次，95%计算
区间会包含真实均值。不意味有95%
概率真实均值在此特定区间。
```

置信区间宽度告诉你精度。宽区间意味高不确定性。窄区间意味估计精确(但未必准确，如数据有偏)。

### t检验

t检验比较均值。有几种类型。

**单样本t检验:** 总体均值是否不同于假设值?

```
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**两样本t检验(独立):** 两组均值是否不同?

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

这是Welch t检验，不假设等方差。
除非特定原因用等方差，总用Welch。
```

**配对t检验:** 当测量成对(相同模型在相同数据划分评估):

```
每对计算 d_i = x_i - y_i
然后在d_i值上对mu_0 = 0运行单样本t检验
```

ML中配对t检验常见: 你在相同10折交叉验证运行两模型并配对比较分数。

### 卡方检验

卡方检验检查观测频率是否匹配期望频率。对类别数据有用。

```
chi^2 = sum((观测 - 期望)^2 / 期望)

例子: 语言模型输出分布是否匹配
跨类别训练分布?

类别    观测   期望
正       120        100
负        80        100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

1自由度，chi^2 = 8 给 p < 0.005。
差异显著。
```

### ML模型A/B测试

ML中A/B测试不同于网页A/B测试。模型比较有特定挑战:

```
1. 相同测试集:    两模型必须在相同数据评估。
                     不同测试集使比较无意义。

2. 多指标: 单精度不够。需要精度、
                     召回、F1、延迟和公平指标。

3. 方差:         用交叉验证或bootstrap估计
                     每指标方差，非仅点估计。

4. 数据泄漏:     如果测试集用于模型选择，
                     比较有偏。保留最终测试集。
```

**流程:**

```
1. 定义指标和显著性水平(alpha = 0.05)
2. 在相同k折交叉验证划分运行两模型
3. 收集配对分数: [(a1, b1), (a2, b2), ..., (ak, bk)]
4. 计算差异: d_i = b_i - a_i
5. 对差异运行配对t检验
6. 检查: 均值差异是否显著不同于0?
7. 计算均值差异置信区间
8. 计算效应量(Cohen's d)判断实践显著性
```

### 统计显著性vs实践显著性

结果可统计显著但实践无意义。有足够数据，微小差异也统计显著。

```
例子:
  模型A精度: 0.9234
  模型B精度: 0.9237
  n = 1,000,000 测试样本
  p值 = 0.001

统计显著? 是。
实践显著? 0.03%改进不值得
部署新模型的工程成本。
```

**效应量**量化差异多大，独立样本大小:

```
Cohen's d = (均值_1 - 均值_2) / 合并标准差

d = 0.2:  小效应
d = 0.5:  中效应
d = 0.8:  大效应
```

总报告p值和效应量。p值告诉你差异是否真实。效应量告诉你是否重要。

### 多重比较问题

测试多假设时，有些会偶然"显著"。如在alpha=0.05测试20件事，即使无真实你期望1假阳性。

```
P(至少一个假阳性) = 1 - (1 - alpha)^m

m = 20测试, alpha = 0.05:
P(假阳性) = 1 - 0.95^20 = 0.64

你有64%几率至少一个假阳性。
```

**Bonferroni修正:** alpha除测试数。

```
调整alpha = alpha / m = 0.05 / 20 = 0.0025

只有p值 < 0.0025才拒绝H0。
保守但简单。测试独立时工作。
```

ML中，跨多指标比较模型、测试多超参配置、或在多数据集评估时这重要。

### Bootstrap方法

Bootstrap通过重采样数据估计统计抽样分布。无需关于底层分布假设。

**算法:**

```
1. 你有n数据点
2. 有替换地抽n样本(某些点多次出现，
   某些不出现)
3. 在此bootstrap样本计算你的统计
4. 重复B次(典型B = 1000到10000)
5. bootstrap统计分布近似
   抽样分布
```

**Bootstrap置信区间(百分位法):**

```
排序B bootstrap统计
95% CI = [2.5百分位, 97.5百分位]
```

**为什么bootstrap对ML重要:**

```
- 测试集精度是点估计。Bootstrap给你
  置信区间。
- 你不能假设度量分布正态(尤其
  对AUC, F1, precision at k)。
- Bootstrap对任意统计工作: 中位、两均值比、
  两模型AUC差。
- 无需闭式公式。
```

**Bootstrap模型比较:**

```
1. 你有模型A和模型B在相同测试集预测
2. 每bootstrap迭代:
   a. 有替换重采样测试索引
   b. 在重采样集计算metric_A和metric_B
   c. 存储 diff = metric_B - metric_A
3. 95% CI差异:
   [diffs的2.5百分位, diffs的97.5百分位]
4. 如果CI不含0，差异显著
```

这比配对t检验更鲁棒因为它无分布假设。

### 参数vs非参数检验

**参数检验**假设特定分布(通常正态):

```
t检验:         假设正态分布数据 (或CLT大n)
ANOVA:          假设正态性和等方差
Pearson r:      假设二元正态
```

**非参数检验**无分布假设:

```
Mann-Whitney U:     比较两组(替代独立t检验)
Wilcoxon符号秩: 比较配对数据(替代配对t检验)
Spearman rho:       秩相关(替代Pearson)
Kruskal-Wallis:     比较多组(替代ANOVA)
```

**何时用非参数:**

```
- 小样本(n < 30)且数据明显非正态
- 序数数据(评分、排名)
- 重异常值无法移除
- 偏斜分布
```

**何时用参数:**

```
- 大样本(CLT使检验统计近似正态)
- 数据大致对称无极端异常值
- 更多统计功效(更好检测真实差异)
```

ML实验中，你典型小n(5或10折交叉验证)，所以Wilcoxon符号秩等非参数检验常比t检验更合适。

### 中心极限定理: 实践含义

CLT说随n增长样本均值分布趋近正态分布，无论底层总体分布。

```
如果X_1, X_2, ..., X_n独立同分布，均值mu方差sigma^2:

    X_bar ~ Normal(mu, sigma^2 / n)    当n -> 无穷

大多数情况n >= 30工作。
对高度偏斜分布，可能需要n >= 100。
```

**为什么这对ML重要:**

```
1. 为聚合指标置信区间和t检验辩护
2. 解释为什么折交叉验证平均给出稳定
   估计即使单折变化大
3. 小批量梯度下降工作因为batch平均梯度
   近似真实梯度(CLT在行动)
4. 集成方法: 多模型平均预测比任一单模型
   给更稳定输出
```

**CLT不做什么:**

```
- 不使你的数据正态。它使样本均值正态。
- 不对无限方差重尾分布工作
  (Cauchy分布)。
- 不应用于依赖数据(时序无修正)。
```

### ML论文常见统计错误

1. **在训练集测试。** 保证过拟合。总保留训练时模型未见数据。

2. **无置信区间。** 报告单精度数无不确定性使结果不可复现不可验证。

3. **忽略多重比较。** 测试50配置报告最佳无修正膨胀假阳性率。

4. **混淆统计和实践显著性。** 0.01%精度改进p值0.001无意义。

5. **不平衡数据用精度。** 99%负类数据集99%精度意味模型什么都没学。用精度、召回、F1或AUC。

6. **樱桃挑选指标。** 只报告模型胜的指标。诚实评估报告所有相关指标。

7. **训练/测试划分间信息泄漏。** 划分前归一化，或用未来数据预测过去。

8. **小测试集无方差估计。** 100样本评估声称2%改进是噪声，非信号。

9. **假设数据独立当非独立。** 同病人医学图像、同文档多句。组内观测相关。

10. **P-hacking。** 试不同检验、子集或排除标准直到得p < 0.05。结果是搜索产物。
