# MIO和任意到任意流式多模态模型

> GPT-4o交付大多数开源模型无法复制产品:听语音、看视频、实时回复agent。2024末开源生态答案是MIO (Wang等，2024年9月)。MIO分词文本、图像、语音、音乐，训练单一因果transformer于交错序列，生成任模态到任模态。AnyGPT (Zhan等，2024年2月)是概念证明；MIO是规模化；Unified-IO 2 (Allen AI，2023年12月)是有视觉+行动 grounding的表亲。这课读任意到任意模式——四种分词器、一transformer、流式友好解码。

**类型:** 学习
**语言:** Python (stdlib，四模态token分配器+流式解码循环)
**前置要求:** 第12阶段·11(Chameleon)，第6阶段(语音和音频)
**时间:** ~120分钟

## 学习目标

- 设计共享词表存文本、图像、语音、音乐token无碰撞。
- 比SEED-Tokenizer(图像)和SpeechTokenizer residual-VQ(语音)于压缩+重建权衡。
- 解释四阶段课程建任意到任意生成。
- 命三个开源任意到任意配方和主要权衡:MIO、AnyGPT、Unified-IO 2。

## 问题背景

统一多模态模型易声称难规模构建。大多"任意到任意"系统至2024是流水线:视觉模型→文本表示→语音模型→音频。每跳失信息、加延迟、复杂训练。GPT-4o demo视频示单模型替代亚秒响应；开源落后数月。

工程挑战:

- 分词器须存每模态，压缩够无损重建，产token于transformer可消费率。
- 单词表须分配空间文本(32k+)、图像(16k+)、语音(4k+)、音乐(8k+)。至少四万加条目。
- 训练数据须覆盖每输入输出对(文本→图像、图像→语音、语音→图像等)或模型须组合。
- 推理须流输出token快够对话延迟(<500ms首音频字节时)。

## 概念讲解

### 四种分词器四模态

MIO分词栈:

- 文本:标准BPE，词表~32000。
- 图像:SEED-Tokenizer (2023)——量化VAE离散码本，4096条目，每图像32x32 token。
- 语音:SpeechTokenizer residual-VQ (2023)——编码16kHz波形8层级码本；第一层粗内容，后层加韵律和说话人身份。
- 音乐:类似residual-VQ (Meta MusicGen / Encodec族)，4-8码本。

每模态产整数token。token得共享词表不相交ID范围:

```
文本:   0..31999
图像:  32000..36095  (4096图像token)
语音: 36096..40191  (4096语音基础token，加残差层)
音乐:  40192..48383  (8192音乐token)
分隔:    48384..48390  (<image>, <speech>, <music>, </...>, 等)
```

总:~48k词表。输入嵌入和输出投影跨全。

### 流式解码

语音生成用residual-VQ。transformer预测基础(层0)语音token；并行解码残差量化器预测后层。每层0 token约16kHz 50ms音频。

流式模式:

1. 用户入mic；实时音频分词器每50ms发语音token。
2. MIO消费token至达(提示预填+增量forward)。
3. 输出token流出生成；并行语音解码器转音频样~50-150ms延迟。
4. 首音频字节时:~300-500ms MIO论文，近GPT-4o~250ms。

Mini-Omni (arXiv:2408.16725)、GLM-4-Voice (arXiv:2412.02612)、Moshi (arXiv:2410.00037)是补充流式语音LLM设计。Moshi单GPU达160ms往返。

### 四阶段课程

MIO训练课程:

1. 阶段1——对齐。大规模模态对语料:文本-图像、文本-语音、文本-音乐。每对用己token词表段。训共享词表。
2. 阶段2——交错。多模态交文档(博客带图像+视频、播客带转录等)。训跨模态上下文。
3. 阶段3——语音增强。额外音频数据提语音质不失文本能力。
4. 阶段4——SFT。跨模态指令调:VQA、标注、叙述、语音到语音对话。

缺阶段退化特定能力:跳阶段2模型失跨模态上下文；跳阶段3语音差。

### 视觉思维链

MIO引视觉思维链:模型发中间图像token作推理步。对"猫爬树否？"模型:

1. 发`<image>` token渲染场景(从输入图或草图)。
2. 发文本分析草图。
3. 发最终答。

渲染中间图像作scratchpad。空间推理任务基准改进。思想镜像文本推理思维链。

### 任意到任意竞争

- AnyGPT (arXiv:2402.12226):4模态(文本、图像、语音、音乐)，类似设计。
- Unified-IO 2 (arXiv:2312.17172):加视觉行动输出、深度、法线。更多任务多样性，更小规模。
- NExT-GPT (arXiv:2309.05519):LLM +模态特定扩散解码器。非单模型方法。
- CoDi (arXiv:2305.11846):可组合扩散；任意到任意经共享latent。

MIO最近纯token任意到任意。AnyGPT是概念祖先。

### 延迟预算

对话产品，每组件延迟重要:

- Mic到音频token:~50ms。
- 预填(音频token+历史):~100ms于8B模型。
- 首输出token:~50ms。
- 并行residual-VQ +语音解码器:~100-150ms。

总首音频字节时:~300ms最小。GPT-4o称~250ms。Moshi称160ms。MIO/AnyGPT于400-600ms范围据公开基准。

### 何任意到任意仍难

2026，开源任意到任意模型闭模型落后两轴:

- 语音质量。Residual-VQ分词器失；对话语音机器声比ElevenLabs级语音。
- 跨模态推理。问模型"唱所见"仍比纯视觉任务更常失败。

这是开放研题。Qwen3-Omni(第12阶段·20课)是2025最先进开源尝试。

## 使用它

`code/main.py`:

- 定义四模态词表分配并印。
- 路多模态输入列表(文本、图像、音频clip、音乐)经分词器路由。
- 模拟流式解码文本到语音响应带延迟计数。
- 计预期首音频字节时给编码器、预填、解码器延迟。

## 发货它

这课产`outputs/skill-any-to-any-pipeline-auditor.md`。给对话产品规格(模态入、模态出、延迟目标)，审计MIO族设计选择算延迟预算。

## 练习题

1. 产品接受语音输入返语音输出。端到端延迟预算目标何？列花时间组件。

2. SpeechTokenizer residual-VQ用8码本。提何并行解码残差层必要(vs序)及何延迟节省。

3. 词表有32k文本+4k图像+4k语音。加8k音乐和~10分隔。嵌入矩阵参数成本何于隐藏维4096？

4. 视觉思维链发中间图像。何问题受益？何问题被额外token伤？

5. 读Moshi (arXiv:2410.00037)。描述"内心独白"技术并比MIO视觉思维链。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|----------|
| 任意到任意 | "多模态入/出" | 单模型接受和发射文本、图像、语音、音乐任方向 |
| Residual-VQ | "语音分词栈" | 多码本分词每层加信息；基础层内容，后层韵律 |
| SEED-Tokenizer | "图像码" | MIO用4096条目离散图像分词器 |
| 视觉思维链 | "视觉scratchpad" | 模型生成中间图像作推理步前最终答 |
| 首音频字节时 | "TTFAB" | 用户语音到首音频输出延迟；<500ms对话感 |
| 四阶段课程 | "训练配方" | 对齐→交错→语音增强→SFT，此序 |
