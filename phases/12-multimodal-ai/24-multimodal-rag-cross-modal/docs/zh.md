# 多模态RAG和跨模态检索

> 视觉原生文档RAG是一切片。生产多模态RAG更宽——跨文本、图像、音频、视频检索工作流如旅行规划("找我安静素食早午餐自然光")、医分流("何伤匹配此照+此笔记")、电商("自拍类似服装，我尺寸")、现场服务("诊断此引擎声加部分照")。2025三调研——Abootorabi等、Mei等、Zhao等——编纂子问题:跨模态检索、检索融合、生成grounding、多模态评估。这课读调研并设计生产流水线。

**类型:** 构建
**语言:** Python (stdlib，跨模态检索器带融合+grounded生成器)
**前置要求:** 第12阶段·23(ColPali)，第11阶段(RAG基础)
**时间:** ~180分钟

## 学习目标

- 设计跨模态检索:文本→图像、图像→文本、音频→视频等。
- 比三融合策略:分融合、注意基融合、MoE融合。
- 解释生成grounding:"引源"何样当源是模态混。
- 命2025三经典多模态RAG调研及其子问题分类。

## 问题背景

单模态RAG是解模式:嵌查询、嵌chunk、检索、填入LLM。多模态RAG需:

1. 多检索头(每模态需兼容空间嵌入)。
2. 跨模态检索结果融合。
3. 生成grounding跨模态引源。
4. 评估指标覆跨模态信号。

2025调研全达同分类。

## 概念讲解

### 跨模态检索

检索模态B文档给模态A查询。三模式:

1. 共享嵌入空间。CLIP和CLAP产文本+图像/文本+音频共享空间嵌入。跨模态余弦相似直工。限于CLIP训对。

2. 每模态编码器+翻译。文编码器+图像编码器+小翻译模块映空间间。Sen2Sen Gupta等2024设计。灵活但加复杂。

3. VLM作编码器。用VLM隐藏态检索表示。VLM支持任何模态工。高质量，更贵。

选:CLIP / SigLIP 2文本+图像；CLAP文本+音频；VLM隐藏态前沿质量跨模态。

### 融合策略

你检索10结果:5图像、3文段、2音频clip。何合？

分融合(最便宜)。每模态有己检索器，每返分。归分模态内后和。简，常工。

注意基融合。拼接全检索项，让小注意网络权重。需训练。

MoE融合。门网络路由模态特定专家。不同查询类型路由不同——视觉问题权重图像更高。

生产默认:分融合轻微偏查询主导模态。若A/B示域明赢升级MoE。

### 生成grounding

LLM应引何检索项驱每声称。多模态:

- 文源:标准引`[1]`。
- 图像源:`[img 3]`带短caption。
- 音频:`[audio 2 at 0:34]`。

训练生成器grounding感知数据:训练目标每声称标源索引。推理，模型自然发引。

### 2025调研

Abootorabi等(arXiv:2502.08826，"任模态问"):多模态RAG分类。覆检索、融合、生成。最宽覆。

Mei等(arXiv:2504.08748，"多模态RAG调研"):聚焦子任务基准和失败模式。评估设计有用。

Zhao等(arXiv:2503.18016):视觉聚焦调研。ColPali族工强。

读全三给你2025春前沿状态。大多子问题仍开。

### MuRAG——基础论文

MuRAG (Chen等，2022)是首多模态RAG。从多模态KB检索图像+文本，生成答案。示VLM浪前可行性。现代系统(REACT, VisRAG, M3DocRAG)建于其。

### 生产旅行规划例

查询:"找我安静素食早午餐自然光。"

流水线:

1. 解构查询。"安静"→音频/评关键词；"素食早午餐"→菜单项；"自然光"→图像特征。
2. 每模态检索:
   - 文检索评:"素食早午餐，安静氛围。"
   - 图检索餐厅照:"自然光，通透。"
   - 音检索环境声clip:"低分贝，无音乐。"
3. 融合分。每餐厅有复合分。
4. Top-k餐厅→VLM生成器全证据→答案带引。

这远文RAG。每模态加文独失信号。

### Agentic多模态RAG

多跳:若首检索不返高置信答案，LLM重构再检索。第14阶段Agentic RAG模式适此。例:

- 检索初top-10→LLM问"太噪，滤<40 dB"→重检索。
- 检索图像→LLM见一有菜单→检索菜单文→答案。

加复杂但处单射检索不能查询。

### 评估

跨模态评估仍不成熟。常代理:

- 每模态Recall@k。
- 融合top-k准确。
- 人评端到端满意。
- 任务特定(预订完，购买完)。

无标准基准跨全模态。大多论文评域特定任务。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|----------|
| 跨模态检索 | "查一模态，检索另一" | 文查询检索图像；图像查询检索文；需共享空间或翻译 |
| 分融合 | "合分" | 每模态检索分权和；最简融合 |
| MoE融合 | "模态路由专家" | 门网络每查询选何模态分信 |
| Grounded生成 | "引源" | 答案每声称标源索引 |
| MuRAG | "首多模态RAG" | 2022论文建多模态RAG模式 |
| Agentic多跳 | "重构重试" | LLM首射置信低重查询检索器 |
