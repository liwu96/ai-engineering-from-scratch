# 生成式Agent与涌现模拟

> Park et al. 2023(UIST '23，arXiv:2304.03442)用三部分架构填充**Smallville**，25 Agent沙盒：**记忆流**(自然语言日志)、**反思**(Agent从自己流生成高层综合)、和**计划**(日级行为，然后子计划)。地标结果是情人节派对涌现：一个Agent种"想开情人节派对"，无进一步脚本，产生邀请传播人口、协调日期、派对发生——从24个起初无知识的Agent。消融示三组件都必需可信度。文档失败是空间规范错误（进关闭店、共享单人卫生间）。这是2026 Agent模拟和多Agent社会评估参考架构。

**类型:** 学习+构建
**语言:** Python(stdlib)
**前置要求:** 阶段16课程04(Primitive Model)、阶段16课程13(Shared Memory)
**时间:** ~75分钟

## 问题背景

多数多Agent系统是紧脚本团队：规划者规划、编码者编码、评审者评审。适定义好任务。不捕捉Agent有记忆、优先级和开放世界时涌现、非脚本行为。研究、社会模拟、日益游戏AI需第二种。

Smallville架构是标杆。直到Park 2023，最好Agent模拟是浅脚本跟随者；之后，模式是开放世界生成式Agent默认。若2026建Agent模拟，你要么用Smallville三组件要么显式说明为何不用。

## 概念讲解

### 三组件

**记忆流。**观察、行动、反思和计划只追加日志。每条有时间戳、类型、描述(自然语言)、派生元数据：**新近度**、**重要性**(Agent自评1-10)、和**相关性**(与当前查询余弦相似度)。

```
[2026-02-14 09:12:03] observation: Isabella Rodriguez问我喜不喜欢爵士
[2026-02-14 09:14:22] reflection:   我享受长时间音乐对话
[2026-02-14 10:05:00] plan:         今晚参加Isabella的情人节派对
```

记忆检索结合三分数：`score = w_recency * e^(-decay * age) + w_importance * importance + w_relevance * cos_sim`。Top-k条进当前提示。

**反思。**周期性(每N条记忆或重要事件)，Agent从近期记忆生成高层综合。反思条回流入流，像其他记忆可检索。这是Agent建"理解"方式——架构等价长期信念。

**计划。**自顶向下分解。先，日级计划粗笔画("去工作，与Klaus晚餐")。然后小时级计划。然后行动级计划。计划可修订：当观察矛盾计划，Agent重规划受影响段。

### 三者为何重要(消融)

Park et al. 跑消融删观察、反思、计划各一。每个消融损可信度：

- 无**观察**Agent错过上下文、基于陈旧信念行动。
- 无**反思**Agent不能形成高层信念；交互保持浅。
- 无**计划**行为变成反应噪声；目标消散。

人类评分者可信度分数三者最高；删任一产生可测量退步。

### 情人节涌现

一个Agent，Isabella Rodriguez，种目标"想在2月14日下午5点Hobbs Cafe开情人节派对"。24其他Agent无此种子。跨模拟日：

1. Isabella计划包含邀请人。
2. 每邀请变成邻居记忆流观察。
3. 那邻居反思生成信念："Isabella开派对。"
4. 那邻居计划纳入"2月14日参加派对。"
5. 邻居告诉其他邻居。邀请无中心协调传播。
6. 2月14日下午5点，几Agent汇聚Hobbs Cafe。

这是技术意义涌现：系统级行为(派对)从局部交互(双边邀请+个体计划)升起，无中心编排者。

### 文档失败模式

Park et al. 显式文档：

- **空间规范错误。**Agent走进关闭店。Agent试用同单人卫生间。Agent在不打算吃的房间吃。模型不单独从环境推断社会-物理规范。
- **记忆溢出。**深模拟跑导致记忆检索成本增。实用补救：周期记忆压缩(总结-剪枝)和低重要性条衰减。
- **反思幻觉。**反思可发明不存在记忆流的关系。缓解：在反思提示含源记忆id并在检索时验证。

这些是生产相关失败模式：任何2026 Agent模拟继承它们。

### 三组件实现规则

1. **记忆只追加。**永不修改记忆条。纠正是新条。
2. **重要性分数便宜。**写时调LLM评重要性1-10。缓存分数。
3. **检索排名非过滤。**组合分数Top-k；不用硬过滤（丢上下文）。
4. **反思周期跑。**当未处理记忆重要性总和超阈值(如150)触发。
5. **计划可修订。**新观察矛盾计划时，只重生成受影响段，非全计划。

### Smallville外生成式Agent

2024-2026后续文献扩展架构：

- **多Agent社会模拟用于政策/市场研究。**Smallville类人口模拟用户响应特征行为。比A/B测试快；精度有争议。
- **游戏NPC AI。**Smallville Agent RPG产生涌现故事线而非脚本任务。
- **生成式Agent评估基准。**而非任务精度，指标变成可信度+长跑行为连贯。

架构是参考。扩展换组件(向量库记忆、检索增强反思、神经符号计划)但保持三部分结构。

### 这为何对多Agent工程重要

Smallville是证明当组件正确多Agent涌现便宜。架构已在开源模型复现(更小LLM可信度优雅而非陡降)。任何需要**涌现社会行为**生产系统用此形。任何需要**紧任务执行**生产系统用本phase早supervisor/roles/primitives模式。

## 构建

`code/main.py`用stdlib Python实现三组件，脚本Agent策略(无真LLM)。Demo复现情人节派对涌现微型：

- `MemoryStream`——带新近度/重要性/相关性检索只追加日志。
- `reflect(stream)`——近期高重要性记忆脚本反思。
- `plan(agent_state)`——基于当前信念日级和小时级计划。
- 场景：5 Agent。Agent 1开始"下午5点开派对"。跨模拟tick，邀请传播、Agent汇聚。

跑：

```
python3 code/main.py
```

预期输出：tick-by-tick轨迹。最后tick，至少5中3 Agent计划示派对，它们汇聚派对地点。单种子产生协调到达无任何编排者。

`outputs/skill-simulation-designer.md`设计生成式Agent模拟：Agent数、记忆schema、反思节奏、计划范围、评估指标。

## 交付成果

生产模拟规则：

- **记忆是数据库。**规模选真存储(向量DB、Postgres)。内存stdlib原型用。
- **记录检索轨迹。**每行动记录驱动它的top-k记忆。这是调试能力。
- **每Agent token预算。**每Agent每tick检索+反思+计划是O(k) LLM调用。N Agent × T tick × 每tick调用可超预算。
- **周期压缩记忆。**总结-剪枝低重要性条。保留策略是设计决策非细节。
- **显式检测空间/社会规范违规**。架构不学它们。

## 练习题

1. 跑`code/main.py`。确认3+ Agent汇聚派对。增Agent到10——涌现仍发生？
2. 删反思步骤。行为像什么？映射Park 2023消融发现。
3. 引入竞争种子目标("Klaus想下午5点做研究讲座")。Agent分裂或一目标主导？什么决定？
4. 加空间约束：Hobbs Cafe最多容纳4 Agent。模拟优雅处理溢出还是打"单人卫生间"失败模式？
5. 读Park et al.(arXiv:2304.03442)Section 6(涌现行为实验)。识别一个你微型不可复现行为。需增强架构哪个组件？

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|------------|----------|
| 记忆流 | "Agent日记" | 观察、行动、反思、计划只追加日志。 |
| 新近度 | "记忆多新" | 按年龄指数衰减分数。 |
| 重要性 | "Agent多关心" | 写时自评1-10。缓存。 |
| 相关性 | "与当前查询多相关" | 余弦相似度(嵌入基础)。 |
| 反思 | "高层信念" | 从近期记忆生成综合，作为新记忆重摄入。 |
| 计划 | "日/小时/行动分解" | 自顶向下计划树。观察矛盾时可修订。 |
| Smallville | "Park 2023沙盒" | 25 Agent模拟产生情人节涌现。 |
| 可信度 | "质量指标" | 人类评分者行为像合理Agent分数。 |
