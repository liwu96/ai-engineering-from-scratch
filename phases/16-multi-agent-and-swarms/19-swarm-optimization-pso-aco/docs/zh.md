# LLM群优化(PSO、ACO)

> 生物启发优化在LLM回归。**LMPSO**(arXiv:2504.09247)用PSO，每个粒子速度是提示，LLM生成下一个候选；适合结构化序列输出(数学表达式、程序)。**Model Swarms**(arXiv:2410.11163)视每个LLM专家为模型权重流形PSO粒子，报告9数据集12基线**13.3%平均增益**，仅用200实例。**SwarmPrompt**(ICAART 2025)混合PSO+Grey Wolf提示优化。**AMRO-S**(arXiv:2603.12933)是ACO启发信息素专家多AgentLLM路由——**4.7x加速**、可解释路由证据、质量门控异步更新解耦推理学习。本lesson实现提示参数空间PSO和Agent路由ACO，测量为何这些经典算法适合LLM时代，何时不适合。

**类型:** 学习+构建
**语言:** Python(stdlib)
**前置要求:** 阶段16课程09(Parallel Swarm Networks)、阶段16课程14(共识与BFT)
**时间:** ~75分钟

## 问题背景

你有一个提示在任务评估62%分。想改进。朴素移动是无梯度手动调，扩展差。强化学习需奖励信号和足够rollout训练。提示反向传播不真可能——提示是离散字符串，非可微参数。

经典生物启发优化——PSO连续搜索空间、ACO路径选择——恰好为此设计：无梯度、种群基、每评估便宜。配LLM做无梯度搜索步，得惊人实用优化器。

同样模式用于多Agent系统Agent*路由*。ACO风格信息素轨迹记录哪Agent哪任务型工作最好，让路由器利用轨迹，衰减信息素使路由可重发现。

## 概念讲解

### PSO复习(Kennedy & Eberhart 1995)

粒子群优化：连续搜索空间粒子群。每个粒子有位置`x_i`和速度`v_i`。每迭代：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中`p_best`是粒子自己最优，`g_best`是群最优，`w, c1, c2`是惯性+认知+社会权重，`r1, r2`是随机因子。

### LLM输出PSO——LMPSO

arXiv:2504.09247适配PSO给LLM生成结构化输出(数学表达式、程序)。每个粒子是候选输出。速度是描述如何修改当前输出向个人/全局最优的*提示*。LLM从速度提示生成新输出。速度"惯性"是提示如"做小增量改变"。

这工作好当：
- 输出结构化(可解析、可评估)。
- 健身自动(测试跑、算术评估)。
- 种群小(~10-30粒子)所以总LLM调用可控。

健身需人审时不工作好——每迭代成本过高。

### Model Swarms

arXiv:2410.11163把PSO从输出层带到*模型*层。每个"粒子"是专家LLM(参数)。群通过无梯度更新移参数向集体最优。报告：9数据集12基线13.3%平均增益，每迭代仅200实例。

关键洞察是LLM专家模型已在共享参数流形附近(adapter权重、LoRA delta)。此低维子空间PSO便宜有效。

### ACO复习(Dorigo 1992)

蚁群优化：蚂蚁遍历图；每路径有信息素轨迹。蚁移动概率权重信息素强度。完成任务蚁按解质量比例沉积信息素。信息素随时间衰减。

### AMRO-S——Agent路由ACO

arXiv:2603.12933用ACO做多Agent路由。每任务型是"目的地"；每Agent是可能路由。信息素增强产好输出路由。关键贡献：

- **可解释路由证据。**信息素强度是人类可读信号。
- **质量门控异步更新。**信息素仅在质量检查通过后更新，解耦推理学习。
- **4.7x加速**多Agent路由基准。

质量门重要：无它，快但错Agent累积信息素，系统锁坏路由。

### LLM何时用PSO/ACO

**用PSO当：**
- 搜索空间连续或映射连续参数(提示嵌入、LoRA权重、数值生成参数)。
- 健身便宜自动。
- 种群可小(10-30)。

**用ACO当：**
- 有路由或路径选择问题。
- 决策随时间加强(同任务型回来)。
- 需路由决策可解释证据。

**都不用当：**
- 健身需人审(每迭代太贵)。
- 搜索空间离散组合PSO不覆盖(用遗传算法)。
- 实时决策需严延迟(PSO/ACO相对于单遍启发收敛慢)。

### 生物启发为何仍赢

梯度基方法需可微信号。LLM输出和路由决策非平凡可微。伪梯度方法(强化学习路由器、DPO风格提示调器)工作但需昂贵训练。

PSO和ACO只需*评估器*函数。若你能评分候选输出或路由决策，你可在空间优化。这使适用门槛低得多。

### 实践限制

- **种群预算。**N粒子 × T迭代 × 每评估成本。LLM评估~$0.02/调用，20粒子PSO跑50迭代~$20。计划。
- **探索vs利用。**信息素衰减率和PSO惯性权衡；太快衰减→忘解；太慢→困早期局部最优。
- **灾难漂移。**两算法可收敛然后发散若健身景观移(新数据分布)。监控最优健身稳定性。

## 交付成果

- **从小开始。**10-20粒子、20-50迭代。仅当收敛曲线显明确增益时扩展。
- **每迭代记录信息素或g_best。**无轨迹调试群优化器痛苦。
- **质量门控更新。**尤其ACO路由：快且错Agent必须不累积信息素。
- **分布移重置衰减。**当评估分布变，老信息素陈旧；重置或临时双衰减率。
- **限每迭代成本。**发出每迭代成本指标。PSO每迭代$500增益0.5%不可部署。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|------------|----------|
| PSO | "粒子群优化" | Kennedy-Eberhart 1995。种群基无梯度优化器。 |
| ACO | "蚁群优化" | Dorigo 1992。信息素轨迹路径/路由优化。 |
| LMPSO | "LLM生成PSO" | arXiv:2504.09247。速度是提示；LLM产候选。 |
| Model Swarms | "专家权重PSO" | arXiv:2410.11163。模型参数子空间无梯度更新。 |
| AMRO-S | "Agent路由ACO" | arXiv:2603.12933。任务型 × Agent信息素矩阵。 |
| p_best / g_best | "个人/全局最优" | 每粒子和群迄今最优解。 |
| 信息素 | "路由记忆" | 边强度；随时间衰减；质量沉积。 |
| 质量门控更新 | "只从好跑学习" | 信息素沉积条件质量检查。 |
| 灾难漂移 | "分布移" | 健身景观变；老p_best和信息素陈旧。 |
