# 失败模式——MAST、群体思维、单一化、级联错误

> 2026参考分类是**MAST**(Cemri et al., NeurIPS 2025, arXiv:2503.13657)，从7个开源MAS 1642执行轨迹导出示**41–86.7%失败率**。三根类：**规格问题**(41.77%)——角色模糊、任务定义不清；**协调失败**(36.94%)——通信崩溃、状态失同步；**验证缺口**(21.30%)——缺验证、缺质量检查。**群体思维**族(arXiv:2508.05687)加：单一化崩溃(同基座模型→相关失败)、从众偏(Agent彼此加强错误)、心智理论不足、混合动机动态、级联可靠性失败。级联例：重试风暴支付失败触发订单重试、触发库存重试、淹没库存服务(秒10x负载——需断路器)。记忆中毒：一个Agent幻觉进共享记忆、下游Agent当事实；精度渐衰、根因诊断痛苦。**STRATUS**(NeurIPS 2025)报告1.5x缓解成功改进通过专用检测/诊断/验证Agent。本lesson视失败模式为一等工程目标。

## 问题背景

多Agent系统真实任务41-86.7%时间失败(Cemri et al. 2025跨7开源MAS测)。非"加更多Agent"可调试。失败有结构原因。MAST分类给你类别。本lesson映射每类别到具体检测、诊断、和缓解模式使数字停止看任意。

2026生产实践视失败模式作设计输入。你架构不"足够好"直到你能指每MAST类别命名你部署缓解。

## 概念讲解

### MAST类别

**规格问题(41.77%失败)。**Agent任务定义不够紧。例：

- 角色模糊：两Agent都以为是评审者。
- 任务欠定："总结此"用户想特定角度。
- 成功准则隐：Agent不能判是否成功。

缓解：
- 写显式角色合同。每Agent提示陈述它做*和不做什么*。
- 每任务接受测试。Agent开始前定义"完成像X"。
- 预飞规格检查：单独Agent派前审任务定义。

**协调失败(36.94%)。**通信或状态崩溃。

例：
- 两Agent无同步更新共享状态。
- Agent间消息丢(队列失败、超时)。
- 状态漂：Agent A认任务完成；Agent B仍执行。

缓解：
- 版本共享状态乐观并发。
- 关键消息显式确认(重试直到ack)。
- 周期状态同步检查点；早检测漂。

**验证缺口(21.30%)。**输出无独立检查。

例：
- 一Agent声称成功；无验证。
- Agent链各信前输出。
- 涌现组合行为测试覆盖缺。

缓解：
- 独立验证Agent(Lesson 13)。只读、独立源访问。
- 显式移交合同："A输出必须过检查器C后B开始"。
- 事后分析结果日志。

### 群体思维族(arXiv:2508.05687)

五相关失败当Agent同化或模仿彼此：

**单一化崩溃。**同基座模型或训练数据→相关错误。三Agent共享LLM时、共享其幻觉。

**从众偏。**Agent调向最大声或最自信的同伴，即使错。

**心智理论不足。**Agent失败建模彼此信念；协调崩溃(Lesson 18)。

**混合动机动态。**部分对齐激励Agent漂向妥协中——满足无人。

**级联可靠性失败。**一组件错误模式触发依赖组件错误模式。

### 级联例——重试风暴

经典2026事故模式：

```
支付服务失败10%请求
   ↓
订单Agent重试支付(指数退避但朴素)
   ↓
每次重试是新订单库存检查
   ↓
库存服务见2x正常负载
   ↓
库存服务开始超时
   ↓
每订单重试库存检查
   ↓
库存服务见10x正常负载
   ↓
集群崩溃
```

修复经典：**断路器**。下游错误率超阈值时，短路缓存或默认结果。加每请求上限重试预算。

断路器是少数多Agent失败缓解你直接从分布式系统借无需修改。

### 记忆中毒(重访)

从Lesson 13：一个Agent幻觉变共享记忆事实；下游Agent基于中毒事实推理。MAST术语，这是共享记忆层验证缺口。

渐精度衰是症状。你不崩溃；你得慢漂难根因。

缓解：只追加日志、provenance、不可写验证器。Lesson 13已覆盖。

### STRATUS——失败检测专用Agent

STRATUS(NeurIPS 2025)报告1.5x缓解成功改进当你部署：

- **检测Agent。**观察症状模式(高分歧、重试激增、精度漂)。
- **诊断Agent。**给定症状、从MAST分类推断可能根因。
- **验证Agent。**缓解应用后、检查症状清。

这是SRE风格事故响应，应用于Agent系统。三角色可都是带专门提示LLM Agent。

### 失败模式审计

2026最佳实践是每年(或每主要发布)失败模式审计：

1. **轨迹样本。**收~1000真实执行轨迹。
2. **分类。**每轨迹失败映射MAST + Groupthink类别。
3. **计算按类失败率。**哪类主导你系统？
4. **排名缓解。**哪修复消最多失败？
5. **选2-3缓解。**实现；下季重审计。

纪律比具体选择重要。无审计，失败混入噪声永不被系统处理。

### 系统静默失败时

最危险失败类是静默正确失败。大声失败(崩溃、异常、告警)系统可监控。产合理但错输出系统不能被异常日志检测。这为何验证缺口按数仅21.30%但每失败最贵类。

投资：
- 基样本人审。
- 金数据集回归测试。
- 重要输出跨Agent交叉检查。

### 失败vs慢失败

些失败立即；些慢。立即失败(超时、schema错配、auth错误)检测便宜。慢失败(记忆中毒、单一化漂、角色模糊)检测防止贵。

2026工程移动：仪表慢失败代理使你可在漂变成可见错误前捕获。共识率、重试率、输出长度分布、和连续Agent版本间编辑距离都是有用代理。

## 交付成果

生产失败模式纪律：

- **每季MAST审计。**非每年。类别随系统增长移。
- **到处断路器。**每出调任何依赖服务。默认开阈值5-10%错误率。
- **金数据集。**小、高质量、手审计。每周回归测。
- **STRATUS三。**检测+诊断+验证Agent监控生产。从检测Agent开始；症状噪声时加诊断。
- **失败预算。**按类失败率显式SLO。超预算触发停运对话。

## 关键术语

| 术语 | 人们怎么说 | 实际含义 |
|------|------------|----------|
| MAST | "2026分类" | Cemri 2025；3根类+14子类型失败。 |
| 规格问题 | "角色模糊" | 任务或角色欠定；Agent不知做什么。 |
| 协调失败 | "状态漂" | Agent间通信或同步崩溃。 |
| 验证缺口 | "无人检查" | 输出接受无独立验证。 |
| 群体思维族 | "同质失败" | 单一化、从众、心智理论不足、混合动机、级联。 |
| 单一化崩溃 | "同模型同幻觉" | 共享基座模型或训练数据相关错误。 |
| 重试风暴 | "级联错误放大" | 一失败触发重试放大下游负载。 |
| 断路器 | "错误率快失败" | 错误率超阈值开；短路默认。 |
| STRATUS | "事故响应三" | 检测+诊断+验证Agent。1.5x缓解成功。 |
| 记忆中毒 | "幻觉传播" | 共享记忆事实污染；下游Agent推理中毒。 |
